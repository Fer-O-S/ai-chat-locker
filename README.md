# AI Chat Locker 🔒

A browser extension to protect your sensitive AI conversations with a PIN.

## 🚀 Features
- Blurs or hides specific chats in your AI's sidebar.
- Requires a local PIN to reveal protected conversations.
- Lightweight, fast, and requires no complex configuration.

## 🛠️ Tech Stack
- **Frontend:** JavaScript, HTML, CSS.
- **Backend (Coming soon):** NestJS, PostgreSQL, Prisma.

## 📥 Installation (Developer Mode)
1. Clone this repository to your computer.
2. Open your browser and go to `chrome://extensions/`.
3. Enable **Developer mode** in the top-right corner.
4. Click **Load unpacked** and select this project's folder.
