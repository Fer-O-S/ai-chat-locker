# AI Chat Locker 🔒

Browser extension to protect your sensitive AI conversations with a PIN.

## 🚀 Características
- Desenfoca u oculta chats específicos en la barra lateral de tu IA.
- Requiere un PIN local para revelar las conversaciones protegidas.
- Ligero, rápido y sin configuraciones complejas.

## 🛠️ Tecnologías (Stack)
- **Frontend:** JavaScript, HTML, CSS.
- **Backend (Próximamente):** NestJS, PostgreSQL, Prisma.

## 📥 Instalación (Modo Desarrollador)
1. Clona este repositorio en tu computadora.
2. Abre tu navegador y ve a `chrome://extensions/`.
3. Activa el **Modo Desarrollador** en la esquina superior derecha.
4. Haz clic en **Cargar descomprimida** y selecciona la carpeta de este proyecto.
